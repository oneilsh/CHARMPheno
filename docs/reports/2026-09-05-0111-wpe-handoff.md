## Config / mechanics notes (so they're not re-derived)

- **Launch:** `make -C analysis/cloud exp ID=111|112` → `run_experiment.py` reads the doc
  front matter merged over `experiments/defaults/episode_mondo_all.yaml`. Both docs carry
  the full 0110 operational block + `index_arm`/`gate_frontier_days: 90`/`episode_*`,
  `preindex_closure: false`, `spark.executor.instances: 20`. Validated locally to emit
  `--index-arm {episode,random} --gate-frontier-days 90 --dag-source mondo_native`.
- **eval_path is inert here and was REMOVED** from both docs: the distributed cell-explode
  needs full-K θ (`topm=0`), but `readout_theta_topm=256` bounds the DRIVER eval collect
  (`test_docs × 256`, sub-GB) — that's the chosen path. The real ×2.66 memory wall is the
  CALIBRATION collect at WP-G, which has its own distributed path (WP-B's other half).
- **Clean-run recipe:** clear the run dir (`rm -rf <RUNS_DIR>/0111-episode-anchored-sampling`)
  so `make exp` doesn't resume off a stale checkpoint. Bundle is a separate cache (HIT) —
  no 20-min rebuild re-paid. `<RUNS_DIR>` = the `runs/` dir holding
  `0110-native-mondo-label-space/`.
- **20 executors:** `instances: 20` fits the 8-primary + 12-spot cluster 1:1 (one 11g
  executor per 13544MB worker). YARN grants what exists and holds the rest pending, so a
  smaller cluster still runs (fewer executors, no error).
- **The readout head-fit** = C=2714 independent convex ridge-logistic regressions (per-node
  linear decode of the frozen topic mix θ → 365d node label), batched in one distributed
  L-BFGS. `max|grad|→0` is the convergence certificate (convex → unique optimum). Ranking
  is stable by ~60 iters (`CHARM_DEV` cap); full `gtol=1e-4` (= sklearn's oracle tol) earns
  its keep only for the calibration probabilities.

## Backlog / possible ADRs

- **gtol / summed-vs-mean loss** (Shawn raised): the absolute `gtol=1e-4` on a *summed*
  loss drifts with `n`, so the bigger episode corpus is held to an effectively stricter
  bar (more stalls). Do NOT quietly loosen gtol (it's the sklearn-oracle tol, load-bearing
  for calibration). For cheap ranking reads use the iter cap. Rescaling to a mean/relative
  loss is a *model change* (regularization balance shifts → different optima/AUCs) — worth
  a deliberate experiment + ADR if pursued, not a tuning tweak.
- **`preindex_closure.py` docstring lag** — rides a future deliberate cache-drop, not on
  its own (source-hashed module).
