# 0159 — gated NPMI on the leaves-first fits (0153–0158)

## Why

Topic coherence has not been measured since the flat-LDA era. The leaves-first work
(insight 0104) was judged by the digest and the own-code census; NPMI is an
independent, word-co-occurrence measure of whether a block's top words belong together.
For node blocks the reference is the documents the gate admits (the user's suggestion:
the same patients the fit used), so a block is scored on the population it describes.
